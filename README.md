One line of weather for a city that does not exist — Glimmerhollow, where snow falls in slow motion at 2°C, so Eda catches one flake, frames it, and misses three buses admiring it. Written for make.fun's ["Charm the Commuter: Forecast a City That Isn't"](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) bounty. Six candidate forecasts were drafted and scored against the judge's criteria in [CANDIDATES.md](CANDIDATES.md); the best one is the entry.

## Run it

```sh
node main.ts
```

This writes the chosen forecast (121 characters) to `output/entry.txt`. Requires Node 22.18 or later (on Node 22.6–22.17, run `node --experimental-strip-types main.ts`).
